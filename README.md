# 华诞 · 头像工坊

一个在浏览器中制作国庆主题微信头像的小工具。选择透明边框模板，添加自己的照片，调整位置与大小，即可下载专属头像。

使用原生 HTML、CSS 和 JavaScript 开发，无需安装依赖或配置后端。照片读取、预览和合成都在浏览器本地完成。

访问地址：[Avatar Studio](https://we11cheng.github.io/avatar-studio/)

## 功能

- **22 款国庆模板**：包含盛世华诞、国庆快乐、我爱祖国、红旗飘扬等主题。
- **透明图层合成**：照片位于底层，PNG 模板叠加在上层，人物透过透明区域显示。
- **照片导入**：支持 JPG、PNG、WebP，单张文件不超过 20 MB。
- **自由调整位置**：支持鼠标或触屏拖动，也可通过左右、上下滑块精细调整。
- **缩放与重置**：缩放范围为初始铺满尺寸的 10%～300%，可一键恢复初始位置和大小。
- **PNG 导出**：保存 1024 × 1024 像素的正方形头像。
- **响应式布局**：适配电脑和手机屏幕。
- **本地处理照片**：应用不会将用户选择的照片上传到服务器。

## 快速开始

### 使用源文件

下载并解压源文件包，使用 Chrome 打开 `index.html`。请保留 `app.js` 和全部模板 PNG 与 `index.html` 在同一目录。

如果使用的是开发项目目录，入口位于 `dist/index.html`。

### 使用离线单文件

使用 Chrome 打开另附的 `头像工坊-离线版.html` 即可。这个文件已内嵌脚本和全部模板，可独立使用；由于包含全部图片，文件体积较大。

### 制作头像

1. 选择喜欢的模板。
2. 点击“选择照片”导入图片。
3. 拖动照片，或使用缩放及位置滑块，使人物完整露出。
4. 点击“下载我的头像”保存 PNG。

> 缩小或移动照片后，照片没有覆盖的区域会显示白底。可通过放大或调整位置补满。100% 表示照片初始铺满画布的尺寸，并非照片原始像素尺寸。

## 文件结构

发布用源文件包的结构如下：

```text
头像工坊/
├── README.md                # 项目介绍与使用说明
├── index.html               # 页面布局、样式与模板列表
├── app.js                   # 照片读取、交互、合成和下载
├── frame-1.png              # 初始宽窗模板
├── frame-2.png              # 初始锦绣模板
├── 01-…-refactor.png        # 新增模板
├── …
└── 20-…-refactor.png
```

开发项目将上述网页文件放在 `dist/` 中。网页不需要构建，发布时使用 `dist/` 里面的文件即可。

## 发布到 GitHub Pages

1. 创建一个公开 GitHub 仓库，例如 `avatar-studio`。
2. 将源文件包解压后的文件上传到仓库根目录。根目录应直接包含 `index.html`、`app.js` 和模板 PNG，不要只上传 ZIP 或额外套一层文件夹。
3. 进入仓库 **Settings → Pages**。
4. 在 **Build and deployment** 中，将 Source 设为 **Deploy from a branch**。
5. 选择 **main** 分支及 **/ (root)** 文件夹，点击 **Save**。
6. 等待发布完成，使用 Pages 页面显示的访问地址。

项目网站地址通常为：

```text
https://<你的用户名>.github.io/avatar-studio/
```

后续上传修改后的文件并提交，即可触发重新发布。具体设置以 [GitHub Pages 官方文档](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site) 为准。

## 添加或修改模板

1. 将新的 PNG 模板放在 `index.html` 所在目录中。建议使用正方形、带真实 Alpha 透明人物窗口的图片。
2. 在 `index.html` 的 `.templates` 容器中追加一个 `.template` 按钮，沿用现有结构。
3. 将 `data-template` 设置为连续索引（从 0 开始），修改图片路径、替代文本和模板名称。
4. 更新页面显示的模板总数。

`app.js` 会从模板按钮自动读取模板数量和图片路径，无需单独维护图片数组。请不要把白色区域或棋盘格图案当作透明窗口；它们会遮住下层照片。

修改源文件后，如需继续分发离线单文件版本，需要重新内嵌更新后的图片和脚本。

## 技术实现

- HTML / CSS：页面结构、样式及响应式布局。
- 原生 JavaScript：模板切换、文件读取、缩放与位移状态管理。
- Canvas 2D：按“白底 → 用户照片 → 模板”的顺序合成。
- Pointer Events：鼠标及触屏拖动交互。
- Canvas `toBlob()`：生成 PNG 文件并触发下载。

模板按需加载，切换模板时保留当前照片及调整状态。导出的头像包含白底，不是透明边框素材。

## 常见问题

**打开后模板没有显示？**  
检查模板 PNG 是否与 `index.html` 同目录，文件名与页面引用是否一致。不要直接在 ZIP 压缩包里打开页面。

**照片移动或缩小后有空白？**  
这是照片未覆盖画布的区域。调整照片位置或放大照片即可。

**在微信内无法下载？**  
可复制链接到 Chrome、Safari 等浏览器中再尝试保存。文件保存方式取决于浏览器和系统。

**修改后还是旧页面？**  
本地使用时重新打开更新后的文件；线上使用时等待部署完成并刷新页面，必要时清除缓存。
